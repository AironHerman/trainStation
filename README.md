# trainStation

A web application designed to dynamically organize and schedule incoming and outgoing train traffic at a station.

## Technologies Used
* **Language:** C#
* **Framework:** ASP.NET Core Razor Pages
* **Database:** Entity Framework Core

## Features
* Schedule and track incoming and outgoing train routes
* Manage station traffic and platform availability
* Data persistence utilizing Entity Framework Core.

## Getting Started
To run this project locally, ensure you have the [.NET SDK](https://dotnet.microsoft.com/download) installed.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AironHerman/trainStation.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd trainStation
   ```
3. **Run the application:**
   ```bash
   dotnet run
   ```
